Размеры картинок Bland Case
===========================

Кейсы:      assets/cases/
  case-auto.png      — автомобильный (сейчас твоё фото 1536x1024)
  case-moto.png      — мото
  case-skins.png     — скины
  case-acc.png       — аксессуары
  case-youtube.png   — ютуберский
  case-admin.png     — админский

Лучший размер кейса: 1024 x 1024 PNG
Можно и 1536 x 1024, как автомобильный — сайт сам впишет.

Предметы:   assets/predmeti/
Имя файла = поле file в js/data.js, например:
  Машина - G63 AMG (0008).png
Лучший размер предмета: 512 x 512 PNG

Фон сайта:  assets/bg.png          1920 x 1080
Баннер:     assets/hero-cars.png   1536 x 1024 (или 1920 x 800)
Логотип:    assets/logo-bear.png   256 x 256 или 512 x 512

Просто замени файл с тем же именем — картинка обновится.
