Arizona Bland Drop
==================

Сайт кейсов в стиле GGDROP / Musor Drop под проект Arizona Bland.
Папка проекта: arizona-bland-drop/

Открытие
--------
Просто открой index.html через любой локальный сервер.

Если открывать файл напрямую (file://), Firebase модули могут не загрузиться —
тогда вход работает локально в браузере.

Пример:
  cd arizona-bland-drop
  python3 -m http.server 8080
  открыть http://localhost:8080


Картинки предметов
------------------
Клади PNG сюда:

  assets/predmeti/

Имя файла должно совпасть с полем file в js/data.js.

Примеры уже лежащих заглушек:
  Машина - Mercedes AMG (0000).png
  Мото - Yamaha R1 (1000).png
  Скин - Business Black (2000).png
  Акс - Rolex Daytona (3000).png
  Админ - Helper Rights (9999).png

Как добавить свою машину из Аризоны:
1) Сделай скрин в игре.
2) Сохрани как PNG с тем же именем, что в data.js
   или добавь новый предмет в js/data.js и новый шанс в нужный кейс.

Firebase
--------
Конфиг уже в js/firebase.js.

В консоли Firebase включи:
- Authentication → Email/Password
- Firestore Database

Правила смотри в firestore.rules и вставь их в консоль Firestore.

Клиентский JS НЕ является защитой. Любой может подделать баланс в браузере.
Для настоящей защиты нужны Firestore rules + Cloud Functions
(списание баланса и розыгрыш кейса только на сервере).


Почему HTML не «в одну строку»
------------------------------
Сжатый HTML не мешает взлому. Это только мешает тебе править сайт.
Реальная защита: правила Firebase, серверный рандом, не светить секреты.
